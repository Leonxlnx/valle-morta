# texgen - procedural PBR texture library for Valle Morta

Every texture in `public/assets/tex/` is generated by the code in this folder
(numpy / scipy / pillow only, no source images). Generation is deterministic:
fixed seeds live in `registry.py`.

## Rebuild

```
set OMP_NUM_THREADS=5
set OPENBLAS_NUM_THREADS=5
.venv\Scripts\python.exe tools\texgen\build_all.py                    # everything, full resolution
.venv\Scripts\python.exe tools\texgen\build_all.py --only moss,roof_tiles
.venv\Scripts\python.exe tools\texgen\build_all.py --only rubble --scale 0.5 --out tools\_preview\tex\dev --preview
.venv\Scripts\python.exe tools\texgen\preview.py rubble,moss,roof_tiles,rust_metal --sheet   # contact sheet
.venv\Scripts\python.exe tools\texgen\check.py                        # files, sizes, seams
```

One process at a time; the FFT / kd-tree workers are capped by `TEXGEN_THREADS`
(default 5). A full build takes a few minutes.

## Outputs (per material, in `public/assets/tex/`)

| file | content |
|---|---|
| `<name>_col.jpg` | sRGB albedo, JPEG q92, no baked lighting (only faint cavity dirt) |
| `<name>_nrm.jpg` | tangent-space normal, OpenGL (+Y / green up), JPEG q95 4:4:4 |
| `<name>_arh.jpg` | R = ambient occlusion, G = roughness, B = height 0..1, JPEG q92 4:4:4 |
| `rust_metal_mask.jpg` | white = olive-drab paint remaining (drive metalness / roughness) |
| `materials.json` | per material: `tile_m`, `size`, `relief_m` (metres spanned by height 0..1) |

The normal maps are derived from the height in true physical units
(`relief_m` over `tile_m`), times a small per-material artistic gain, so
`normalScale = 1` is the intended look. `relief_m` is the right value for
parallax / displacement scale.

## Code layout

- `core.py` - the toolkit. Periodic noise (spectral gaussian fBm that is
  resolution independent, value, Perlin, rotated-lattice "simplex-like" fBm,
  billow, ridged), periodic Worley/Voronoi (F1, F2, cell id, exact edge
  distance, Lloyd relaxation), domain warp, slope blur, thermal erosion, flow
  accumulation, sediment fill, downward streaks, periodic distance transform,
  height -> normal, horizon-based AO, curvature, analytic shape stamping with
  wrap (`stamp`, `blob_fn`, `poly_fn`, `pack_discs`), a supersampled id-buffer
  rasteriser for blades / needles / twigs (`Raster`), random-walk cracks
  (`crack_map`), coursed layouts (`course_layout`), colour ramps, `finalize`.
- `stones.py` - packed stone scatter shared by the ground materials.
- `mat_<name>.py` - one module per material: `build(ctx)` returns height in
  metres, sRGB albedo and roughness; `finalize` derives normal + AO and saves.
- `registry.py` - tile size, resolution and seed of every material.
- `build_all.py` - builds everything (`--only a,b`, `--scale`, `--out`, `--preview`).
- `preview.py` - numpy renderer (low sun + sky ambient + GGX + height-field
  shadows + filmic tonemap) writing `tools/_preview/tex/<name>.png`.
- `check.py` - verifies files, dimensions and seam continuity.

Everything is authored in metres (`ctx.noise(tag, longest_wavelength_m, shortest_wavelength_m)`),
so feature sizes are correct for the stated tile size and identical at any
resolution; all operators are periodic, so the tiles are seamless by construction.
