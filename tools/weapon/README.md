## Commands

```
# everything (arms, then every weapon that has a w_<id>.py), with final sheets and verification
powershell -NoProfile -File tools\weapon\build_all.ps1
powershell -NoProfile -File tools\weapon\build_all.ps1 -Only rifle -Stages anim      # one target, chosen stages

# single stages (Git Bash wrapper: runs Blender with 6 threads, log in build/<logname>.txt, prints the interesting lines)
bash tools/weapon/run.sh mylog arms geo bake tex test
bash tools/weapon/run.sh mylog rifle geo bake tex anim look sheets=Reload:12,ReloadEmpty:12,misc
bash tools/weapon/run.sh mylog rifle anim sheets=Reload:12 noexport          # animation iteration: about 45 s + 2 s per tile

.venv\Scripts\python.exe tools\weapon\verify_glb.py public\assets\models\rifle.glb
```

Stages: `geo` (geometry, atlas UVs, node split -> `build/<id>.blend`), `bake` (part id / position / normal / bevel-normal / AO maps as `.npy`, about 80 s), `tex` (`surf.py`, numpy only, about 35 s -> `build/<id>_{base,nrm,orm}.png`), `anim` (grips, clips, optional previews, actions, GLB, sidecar, verify, `build/<id>_final.blend`). Options of `anim`: `look` (6 model views -> `tools/_preview/weapon/final_<id>_model.png`), `sheets=Clip:frames,...,misc` (first-person contact sheets `final_<id>_<Clip>.png`, `misc` = the module's `MISC` list on one sheet), `noexport`. The arms must be built before any weapon `anim` stage.

## File map

| `rig.py` | glove + sleeve geometry, armature, skinning, and the posing library `Rig` |
| `anim.py` | `Tr` tracks, `spring` / `kick`, `Anchor`, `HandTrack`, `Clip`, `Stage` (grips, per-frame solve, diagnostics, actions + NLA), `run()` (previews, export, sidecar) |
| `w_rifle.py` | rifle: detail geometry pass, grips (`setup`), clips (`clips`) — the template for new weapons |
| `surf.py` | texture synthesis per atlas: `load`, material functions, `common()` (default material per id), per-atlas hooks, `finish` (height -> normal map, ORM) |
| `textures.py` | older module, kept only as a library of material functions (`m_wood`, `m_cloth`, `m_leather`, `m_pad`, `m_bolt`, `m_brass`, `stamp_text`, `fbm` ...) imported by `surf.py` |
| `sheet.py`, `verify_glb.py` | contact-sheet assembly (venv), GLB contract check |

Axes: Blender +X right, +Y muzzle, +Z up; origin at the pistol grip; the exporter converts to glTF (+Y up, barrel along -Z). Geometry is authored in mm, all animation / rig API values are metres and degrees.

## Arms rig

- Geometry (`rig.build_glove`, `build_sleeve`): the glove is a union of swept volumes (palm slab, five fingers from `rigdef.FING` / `TH`, thenar, web, hypothenar, knuckle guard, wrist strap) that is voxel-remeshed (1.1 mm), smoothed and decimated to 7000 triangles; the sleeve is a folded loft that closes over the glove cuff. Only the right arm is unwrapped and baked; `build_skinned` mirrors it, so both arms share one 2048 texture set (mirrored UVs).
- Bind pose: both arms straight along +Y, palms down, wrists at x = ±0.2 m. Bones per side (`_R`, `_L`): `UpperArm`, `Forearm`, `Hand`, then `Thumb1..3`, `Index1..3`, `Middle1..3`, `Ring1..3`, `Pinky1..3` (36 joints). Hand frame: +Y towards the fingers, +Z back of the hand, +X little-finger side for the right hand (thumb side for the left).
- Weights are analytic (`rigdef.glove_weights`, `sleeve_weights`): arclength blends at the finger joints, knuckles stay with the hand on the back side, thenar follows `Thumb1`, cuff blends into the forearm.
- Textures (`surf.hook_arms`) are computed in rest-pose hand coordinates: fabric back, leather palm with stitched patches, rubber knuckle guard, webbing strap, sleeve hem and seam.

## Posing library (`rig.Rig`)

- Finger poses are angle sets in degrees with right-hand semantics (the left hand is mirrored automatically): fingers `[curl1, curl2, curl3, spread]`, thumb `[palmar elevation, swing towards the index, pronation, curl2, curl3]`. `pose(a)` turns a set into a (15, 4) quaternion array; `pblend` interpolates arrays; `pre(a)` is the opened version of a grip. Presets: `A_OPEN`, `A_RELAX`, `A_SPREAD`, `A_HOOKED`, `A_FIST`.
- `seat(bvh, side, R, p, g, approach)`: puts hand point `g` (mm) at `p` with rotation `R` (`rig.frame(finger_dir, dorsal_dir)`), backs off and pushes along `approach` until the palm proxy spheres touch.
- `close(...)`: curls every finger joint in 2° steps until its collision spheres touch the BVH; the thumb is aimed across the object (`thumb=dict(aim=..., flex=...)`, hand-space vectors), pronated so that it flexes towards `flex`, then curled until contact.
- `reach(side, Hm, a, finger, target)`: grid search + refinement that puts a finger pad on a point (used for the trigger finger, at rest and pulled).
- `proxy(side, Hm, pose)`: low-poly hull of a posed hand, to add the firing hand to the BVH when the support hand must wrap it (needed for the two-handed pistol grip: `rig.bvh_of(meshes, extra=rg.proxy(...))`).
- `solve(side, shoulder, Hm, pole)`: analytic two-bone IK; the forearm carries the full twist of the hand; if the target is out of reach the (virtual) shoulder slides. `channels(...)` converts to pose-bone values.

## Clip authoring (`anim.py`, see `w_rifle.py`)

A weapon module defines `ID`, `PIVOT`, `EYE` (preview camera, 52° vertical FOV, looking along +Y), `GROUPS` (node order), `PARTS` (animated nodes, parents first), `SHOULDER`, `POLE`, `VIEWS`, `MISC`, optional `CAMS` (per-clip preview camera), `MOVERS` (nodes with their own collision tree, default `['Magazine']`), `ONLY` (`{node: [clips]}` — the node is keyed only in those clips, meant for `BipodL` / `BipodR`), `META`, and three functions:

- `geometry()` -> `dict(groups, origins (mm, node pivots), parents, uvs (tag -> texel scale), empties (mm))`.
- `setup(st)`: grips. `st.grip(name, side, parent_node, R, p, g, approach, fingers=..., thumb=..., reach=..., retreat=...)` returns an `Anchor` (wrist matrix relative to the parent node, closed pose, opened pose, retreat vector). It prints `GRIP ... depth x mm` (residual penetration) and the solved angles. Set `st.base = {'R': ..., 'L': ...}` (idle grips).
- `clips(st)`: one `Clip(st, name, seconds, loop)` each. Tracks: `c.wp` / `c.wr` (weapon offset in m, rotation as pitch, roll, yaw in degrees about `PIVOT`; + pitch = muzzle up, + roll = top to the right, + yaw = muzzle left), `c.pp[node]` / `c.pr[node]` (part offset / Euler XYZ about the node origin), `c.ps[node]` (uniform scale track, e.g. `MagRounds`), `c.sh[side]` (shoulder offset), `c.pl[side]` (added to the IK pole), `c.ev(t, name)` (sidecar events). `Tr.k(t, value, tan, ease)`: `tan='s'` stops at the key, `'c'` flows through it; `ease` (`in`, `out`, `io`, `lin`, `in3`, `out3`, `back`) replaces the spline for the segment ending at the key (use `in` for impacts). `Tr.add(spring(...))` / `kick(...)` add reactions; they are faded out over the last 0.1 s of non-looping clips.
- Hands: `c.hand[side].clear().hold(t0, t1, anchor, close=, open=, mid=, lift=)`. Inside a hold the hand is rigidly attached to the anchor's parent node (so animating `Magazine` moves the hand with it); `close` / `open` are the seconds the fingers take to close after arriving / open before leaving. Between two holds the wrist follows a cubic Bézier that leaves and arrives along the anchors' retreat vectors (+ `lift`, world space), the rotation is slerped, the fingers go through `mid` (default relaxed; `mid='direct'` blends the two poses directly; a pose array gives a custom in-between).
- Per-clip log line: `CLIP name | wrist bend R/L (max angle forearm vs hand, all frames including off-screen ones) | shoulder slid (frames where the reach clamp moved the shoulder) | deepest contact (hand spheres vs weapon, only reported above 4.5 mm, with time)`. Clips whose first / last frame differ from Idle frame 0 are listed (expected for Draw start, Holster end, Sprint).
- Export (`Stage.actions`, `wlib.export_glb`): one Blender action per clip and object (slotted actions, Blender 5), each pushed to an NLA track named like the clip; exporter mode `NLA_TRACKS`, sampled at 60 fps. Idle is pushed last and `export_rest_position_armature=False`, so the default node pose of the GLB is Idle frame 0. Durations must be multiples of 1/60 s.

## Building the pistol and the sniper

1. Copy the structure of `w_rifle.py` to `w_pistol.py` / `w_sniper.py`; write `geometry()` from scratch with the `geo` primitives (use `geo.GROUPS.clear()` semantics: `build.py` clears it). Required nodes are listed in `verify_glb.py` (`NEED`, `COMMON`); `Casing` must be a group parked inside the weapon, `ScopeEye` an empty.
2. Add texture detail to `hook_pistol` / `hook_sniper` in `surf.py` (the rifle hook shows stamped text via `T.stamp_text`, dimples, extra wear). `common()` does not handle `GLASS`: call `m_glass(c, mask, (x, z) of the lens axis)` from the hook.
3. Pistol: `PARTS = ['Slide', 'Magazine', 'Trigger', 'Hammer']`; firing grip like the rifle (knuckles diagonally in front of the front strap, see pitfalls); seat the left hand against a BVH that includes `rg.proxy('R', ...)`; clip lengths 1.7 / 2.1 / 0.3 / 0.3 s; `Fire` cycles `Slide` and `Hammer`; `ReloadEmpty` should move the slide to the locked position in the first frames and end with the `slide_release` event; put the lock offset into `META`.
4. Sniper: `PARTS = ['BoltHandle', 'Magazine', 'Trigger', 'BipodL', 'BipodR']`, `ONLY = {'BipodL': ['BipodDeploy'], 'BipodR': ['BipodDeploy']}`, `Scope` as a static node. For the bolt knob use `Anchor(parent='BoltHandle', ..., pivot=knob centre (parent space), rotpar='Weapon', follow=0.3)` so the hand follows the knob position but not its full rotation. Clip lengths 3.2 (Reload) and 1.1 (BoltCycle).

## Pitfalls already hit

- A finger only wraps tightly if its knuckle sits diagonally outside the corner it bends around (about one finger radius in front of the surface it crosses). With the knuckle behind the corner the finger forms a loose loop.
- `close()` skips a joint that already collides at the start; start from `A_HOOKED` (default) for wrap grips and from `A_OPEN` when the hand comes down onto the object (rifle `charge` grip).
- The thumb needs pronation to oppose; the parametrisation by elevation / swing / twist plus `thumb_aim` exists because plain abduction angles could not reach around a grip.
- An anchor on a part that snaps away (bolt, slide) drags the transition start with it: switch to a `Weapon`-parented release anchor first (rifle `A['rel']`).
- A reload must lift the weapon into the frame (rifle `RP`, `RR`); at the idle position the magazine well is below the lower frame edge.
- Taking a finger out of the trigger guard by blending angles clips the guard; use an in-between pose (rifle `st.IDX`) — still not clean, see below.
- `uv_unwrap` scales tagged parts about the origin; a tag must cover whole disconnected parts.
- Blender 5.2 has no `action.fcurves`; fcurves live in `layer.strips[0].channelbag(slot)`; NLA strips need `action_slot` set.
- Git Bash `python` prints "Could not find platform independent libraries" — harmless.

## What I would improve on the rifle

- Contacts reported by the last solve: trigger finger vs trigger guard 10 mm at 0.05 s of both reloads; support hand vs receiver 9 mm at 0.35 s (approach to the magazine) and 12 mm at 1.92 s of `ReloadEmpty` (on the way over the top); thumb vs magazine 9 mm while approaching / releasing. Fix with `lift` vectors and better in-between finger poses.
- `Fire` was only checked from a side camera at 6 sampled frames, which miss the 17–33 ms frames where the carrier is fully back; the trigger-finger squeeze is not verified visually. Add an explicit frame list to the sheet option.
- `ReloadEmpty` rack: the hand over the receiver is not verified at close range (hook on the handle), and the released hand passes close to the camera and looks large at 2.45 s.
- `Sprint`: support wrist bent about 56°; `Draw` / `Holster`: firing wrist about 64° in the off-screen frames; the right shoulder slides for 14 frames in the reloads (move `SHOULDER['R']`).
- Surface: the steel is very dark, the weapon normal map carries little detail (0.15 MB JPEG), wear is subtle. Geometry is the earlier build plus a detail pass (rivets, ribs, magazine lugs / lips / floor plate, second round, casing), not a clean-sheet model.
- Thumb pronation shears the glove at the thumb base; fingertips stand slightly proud of the upper handguard.
