# Valle Morta

A first-person zombie survival shooter set in a war-ruined alpine valley, running in the browser on three.js (WebGL2).

Every visual asset is generated by code in this repository: the eroded mountain range, the valley, the ruined village and its church, the broken bridge, the river, grass and trees, the tank wreck, the rifle, the infected and all 22 PBR texture sets. No premade models or textures are used. Sound effects and music are licensed third-party recordings (see Credits).

## Run it

```bash
npm install
```

```bash
npm run dev
```

Then open http://127.0.0.1:5173. A GPU with WebGL2 is required; the game is tuned on an integrated Radeon 780M and has four quality presets in Settings.

## Controls

| Action | Input |
|---|---|
| Move | W A S D |
| Look | Mouse |
| Fire | Left mouse button |
| Aim down sights | Right mouse button |
| Reload | R |
| Sprint / jump / crouch | Shift / Space / Ctrl |
| Pause | Esc |

Waves of infected leave the village and come for you. Head shots kill; ammunition is resupplied between waves.

## How it is built

- `src/engine` — HDR renderer: ray-marched volumetric clouds baked progressively into a sky panorama, a matching cloud-shadow map that drives sun patches and light shafts, height fog, ambient occlusion, bloom, filmic tone mapping with an HDR10 (PQ) output path.
- `src/world` — terrain clipmap and far mountain mesh, procedural buildings and bridge, GPU-placed grass, trees, water, props.
- `src/game` — player controller, rifle, zombie AI with flow-field navigation and per-bone hit volumes, wave director, effects, audio.
- `src/cinematic` and `cinematic/capture.mjs` — a scripted 45 second film rendered from the live game.
- `tools/` — offline generators: `bake-terrain.mjs` (erosion-simulated terrain), `texgen/` (PBR textures, Python + numpy), `zombie/`, `weapon/`, `props/` (Blender scripts for the character, rifle and tank).

Useful commands:

```bash
node tools/bake-terrain.mjs
```

```bash
node tools/playtest.mjs
```

```bash
node cinematic/capture.mjs
```

The last one renders the film at 3840x2160, 24 fps, HDR10 into `cinematic/valle-morta-4k-hdr.mp4` (needs Chrome, ffmpeg with libx265, and the dev server running). Add `--stills` for a quick framing check.

## Known limitations

- The look is a real-time approximation of the photographic references it was built from, not a match for them.
- The rifle and the infected are fully procedural and show it at close range.
- There is no church bell recording and no wood-footstep sound in the audio set.
